# 2b2t Community anti spam

This is a Meteor Plugin that blocks specific players chat messages

## Installation
Copy the .jar file from the release page to your mods folder with meteor installed

# Usage
Enable the plugin to block all players on the block list. Toggle 

## Commands

- `communityblock block <player>`: Block a player locally
- `communityblock unblock <player>`: Unblock a player locally
- `communityblock copy <player>`: Copy a player's name and uuid to your clipboard
- `communityblock export`: Export all blocked players to your clipboard
